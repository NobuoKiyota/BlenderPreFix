# 野生のシダ植物群生 (Wild Fern Cluster) 最小単位モデリング手順 ＆ Why深層分析

太古の森の林床を覆う、フィボナッチ螺旋展開する優美な羽状複葉、光を透かす半透明SSS葉身を持つシダ群生の全行程レシピ。

---

## 最小単位全手番レシピ (Atomic Steps)

| Step | 操作 (Key / Action) | パラメータ / 設定値 | 手順の目的・理由 (Why) |
| :--- | :--- | :--- | :--- |
| **#001** | `Shift + A` > `Curve` > `Bezier` (シダ主軸カーブ / Fern Frond Stipe) | 長さ: 0.65m, 放物線アーチ | 根元から外側へ噴水のように弧を描いて垂れ下がるシダの葉軸を定義。 |
| **#002** | Curve Data > `Bevel Geometry` > `Depth: 0.004m` | 先細り円柱軸 | 根元が太く先端が細いしなやかな葉軸を作成。 |
| **#003** | `Shift + A` > `Mesh` > `Plane` (小羽片 / Pinna Leaflet) | Length: 0.06m, Width: 0.018m | 葉軸の両側に並ぶ小さな葉（羽片）のマスターピース。 |
| **#004** | `Tab` (Edit Mode) > 先端を尖らせ、外周にギザギザ（鋸歯）を入れる | 典型的なシダ葉形 | ノコギリ状の鋸歯を持つシダ特有のシャープなシルエット。 |
| **#005** | 小羽片を葉軸の左右に交互に配置（計16対） | 基部は大きく、先端は縮小 | 先端に向かって段階的に小さくなる羽状複葉（Pinnate Leaf）を構築。 |
| **#006** | 葉軸と全小羽片を結合 (`Ctrl + J`) | 1本の完成葉 (Frond) | クラスター展開のマスターオブジェクトを作成。 |
| **#007** | 原点を葉の付け根（根元）に設定 | 回転ピボット | 根元を中心に放射状に旋回配置できるようにする。 |
| **#008** | `Shift + D` で複製 > `R > Z: 45 deg`, `R > Y: -10 deg` (傾きオフセット) | 第2の葉 | 黄金比の角度で回転させ、自然な重なりを作る。 |
| **#009** | 同様に計8本の葉を360度放射状に配置 | 全方位ロゼット展開 | 中心から外へ噴水状に広がる優美なシダの株（Cluster）を完成。 |
| **#010** | 中央に小さくゼンマイ状に丸まった新芽（Fiddlehead）を追加 | `Curve` 螺旋スパイラル | 春の芽吹きを感じさせる愛らしくリアルな植物学的ディテール。 |
| **#011** | 株の根元にこんもりとした土壌マウンド (`Cylinder`, 半径 0.2m) を配置 | 植生ベース | 鉢植えやゲーム背景アセットとして即座に地面に馴染む土台。 |
| **#012** | `Material Assign` > `M_Fern_Leaf` | シダの全葉 | 鮮やかなエメラルドグリーン（Subsurface: 0.3, Transmission: 0.12）。 |
| **#013** | `Material Assign` > `M_Fern_Stipe` | 葉軸 | 少し黄みがかった硬質ケラチン木質。Roughness 0.45。 |
| **#014** | `Material Assign` > `M_Fern_Soil` | 根元の腐葉土 | 黒っぽい湿った土。Roughness 0.95。 |
| **#015** | 葉の表面に微細な葉脈バンプ（Wave Texture, Scale 80）を付与 | 筋状の葉脈 | 近接カメラ撮影でも耐えられるリアルな葉のディテール。 |
| **#016** | ランダムな葉先にわずかな枯れ・茶変色（ColorRamp Blend）を導入 | 自然の不完全さ | 完璧すぎるCG感を消し、生きている本物の野草の風合いを付与。 |
| **#017** | スタジオトップライト＋斜め後方リムライト | 逆光透過光 | 葉を透過して光る鮮烈なグリーンのサブサーフェスを強調。 |
| **#018** | 風による揺れモディファイア（Displace Texture: 周期ノイズ） | アニメーション準備 | ゲームエンジンで風揺れシェーダーを適用しやすいトポロジー。 |
| **#019** | 全トランスフォーム適用 (`Ctrl + A`) | All Transforms | スケール統一。 |
| **#020** | Cycles パストレーシングレンダリング | Samples: 32, Denoise: ON | 幾重にも重なった葉が落とす柔らかな透過影をパストレース計算。 |
