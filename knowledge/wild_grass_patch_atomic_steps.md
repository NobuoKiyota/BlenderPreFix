# 野生の草原・草の塊 (Wild Grass Patch) 最小単位モデリング手順 ＆ Why深層分析

風になびく自然な弧を描く草ブレード群、根元（深緑土色）から先端（陽光黄緑）へのグラデーション、地面土壌を持つ草むらアセットの全行程レシピ。

---

## 最小単位全手番レシピ (Atomic Steps)

| Step | 操作 (Key / Action) | パラメータ / 設定値 | 手順の目的・理由 (Why) |
| :--- | :--- | :--- | :--- |
| **#001** | `Shift + A` > `Mesh` > `Plane` (地面ベース / Soil Mound) | Size: 1.2m, Location: (0, 0, 0) | 草むらが生い茂る土台となる地面を作成。 |
| **#002** | `Tab` (Edit Mode) > 中央部を上へ引っ張り、なだらかな丘状に成形 | こんもりとした土壌 | 平坦な板ではなく、自然な野原の起伏を表現。 |
| **#003** | `Shift + A` > `Mesh` > `Plane` (マスター草ブレード / Single Grass Blade) | Scale: (0.015m, 0.45m, 1.0) | 1本の細長いイネ科植物の葉を作成。 |
| **#004** | `Tab` (Edit Mode) > 長さ方向に4分割ループカット (`Ctrl + R`) | 4分割トポロジー | 風でしなやかに曲がるアーチ状の変形を可能にする。 |
| **#005** | 先端頂点を結合 (`M > At Center`) して尖らせる | 尖った葉先 | 自然な草ブレードの鋭利な先端を形成。 |
| **#006** | `S` > 根元を少し太く、先端を細くテーパー成形 | 自然な葉身 | 根元の剛性と先端の柔軟性を幾何学的に表現。 |
| **#007** | プロポーショナル編集で葉の上半分を前方斜め下へ弓なりに湾曲 | 優美なしなり | 重力と風で自然に垂れ下がる草のカーブを作成。 |
| **#008** | 原点を草ブレードの根元最下部に設定 | 回転支点固定 | 地面に接した根元を軸に回転・スケールできるようにする。 |
| **#009** | `Shift + D` で複製し、角度とスケールを変えて8本を小さな束（Tuft）にまとめる | 草の小株 (Tuft) | 1本立ちではなく、密集して生える草の基本房を作成。 |
| **#010** | 作成した束を地面マウンド上に等間隔＋ランダム回転で12箇所に配置 | クラスター展開 | 外側に向かって低く、中央が高くなる自然な草むらを構築。 |
| **#011** | 全草ブレードを選択して結合 (`Ctrl + J`) | 単一メッシュ化 | ゲームエンジンでの頂点カラー風揺れシェーダーの最適化。 |
| **#012** | シェーダーエディタでグラデーションノード（Z軸グラデーション）を構築 | `Linear Gradient` (Z: 0〜0.45m) | 根元は暗い湿りオリーブグリーン、先端は日光を浴びた明るいライムグリーン。 |
| **#013** | `Subsurface Scattering` (0.2) を設定 | 葉の光透過 | 太陽の光を浴びた時に草むら全体が輝いて見える瑞々しい表現。 |
| **#014** | `Material Assign` > `M_Wild_Grass` | 全草ブレード | 自然なグラデーション草マテリアル。Roughness 0.48。 |
| **#015** | `Material Assign` > `M_Grass_Soil` | 地面マウンド | 枯草混じりの黒土。Roughness 0.95。 |
| **#016** | 地面に数本の乾いた枯れ草（茶褐色）をアクセント配置 | 自然のリアリズム | 青草だけの人工感を消し、四季の移ろいを感じさせる。 |
| **#017** | 法線編集モディファイア (`Normal Edit`) で法線を上向き（Z+）に統一 | 影の潰れ防止 | 密集した草の内側が真っ黒に潰れるのを防ぎ、柔らかなライティングを実現。 |
| **#018** | 低角度からの夕日色サンライト（暖色オレンジ, 400W） | ドラマチック夕景 | 草原の先端が黄金色に輝く美しいバックライト照射。 |
| **#019** | 全トランスフォーム適用 (`Ctrl + A`) | All Transforms | スケール統一。 |
| **#020** | Cycles レンダリング (被写界深度で背景を優美にボカす) | シネマティック草むら | 手前の草にピントを合わせ、自然の美しさを際立たせる構図。 |

## マテリアル ＆ サウンド設計 (Audio & Physics)

| スロット名 | 材質分類 (Surface Type) | Wwise / CRI Audio Tag | シェーダー設定の要点 |
| :--- | :--- | :--- | :--- |
| **M_Wild_Grass** | Foliage_Grass_Lush | Sound_Grass_Footstep_Rustle | 青草。Z軸グラデーション、SSS 0.2、粗さ 0.48。 |
| **M_Dry_Grass** | Foliage_Grass_Dry | Sound_Dry_Grass_Swish | 枯草。黄褐色、Roughness 0.72。 |
| **M_Grass_Soil** | Dirt_Soil_Muddy | Sound_Soil_Soft_Mud | 黒土。Roughness 0.95、微細バンプ。 |
