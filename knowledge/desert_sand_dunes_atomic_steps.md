# 砂漠の砂紋・砂丘 (Desert Sand Dunes) 最小単位モデリング手順 ＆ Why深層分析

風が刻む優美な風成砂紋（リップル）、シャープな風下稜線（スリップフェイス）、鉱物粒子の微小スパークルを持つ砂丘ジオメトリの全行程レシピ。

---

## 最小単位全手番レシピ (Atomic Steps)

| Step | 操作 (Key / Action) | パラメータ / 設定値 | 手順の目的・理由 (Why) |
| :--- | :--- | :--- | :--- |
| **#001** | `Shift + A` > `Mesh` > `Plane` (砂丘メッシュ / Dune Terrain) | Size: 3.5m, Location: (0, 0, 0) | 砂漠の地形を作成するベースプレーン。 |
| **#002** | `Tab` (Edit Mode) > 細分化 (`Subdivide: 48`) | 2304フェース | 砂丘のなだらかな斜面と鋭い稜線を表現するための分割密度。 |
| **#003** | 稜線となる対角線の頂点ループを選択 > `G > Z: 0.65m` で持ち上げ | 主砂丘稜線 (Dune Ridge) | 風によって形成されるバルハン砂丘の鋭い尾根（Crest）を作成。 |
| **#004** | 風上側（Stoss Slope）を緩やかな傾斜（15度）にする | 緩斜面 | 風が砂を押し上げて運ぶなだらかな斜面。 |
| **#005** | 風下側（Lee Slope）を急な傾斜（32度、安息角）にする | スリップフェイス (Slip Face) | 砂が崩れ落ちる物理限界角度（安息角）によるシャープな断崖稜線。 |
| **#006** | `Modifier` > `Displace` (風成砂紋リップル) > Wave Texture | Direction: 風向きに直交, Strength: 0.012m | 風の規則的な息吹によって砂面に刻まれる美しい縞模様の砂紋を立体化。 |
| **#007** | `Right Click` > `Shade Smooth` | スムースシェード | 広大で柔らかな砂の丘の曲面を担保。 |
| **#008** | シェーダーエディタで新規マテリアル `M_Desert_Sand` を作成 | 砂漠シェーダー構築 | 鉱物粒子の光学的特性を定義。 |
| **#009** | Base Color: 暖かな黄金琥珀色 (0.88, 0.62, 0.35, 1.0) | サハラ砂漠の黄金砂 | 酸化鉄で赤みを帯びたクォーツ（石英）砂の色合い。 |
| **#010** | Roughness: `0.78` | 乾いた砂質 | 無数の微小砂粒が光を全方向に乱反射するマットな質感。 |
| **#011** | `Subsurface Scattering` (0.08, 暖色オレンジ) | 砂の透け感 | 砂粒の隙間を光が微小浸透する柔らかな温もりを演出。 |
| **#012** | 微小スペキュラスパークル（Noise: Scale 350, Metallic 0.2）をブレンド | 石英結晶のきらめき | 直射日光を受けた砂丘の表面でキラリと微小に光る水晶粒子の反射。 |
| **#013** | 砂紋の谷間に薄い影を落とすアンビエントオクルージョン調合 | リップルの立体感 | 遠景でも砂紋の波がくっきりと見えるコントラスト強化。 |
| **#014** | 砂丘の一角に乾いた風化頭骨または枯れ木片を配置 | 砂漠の過酷な物語 | スケール感と砂漠の孤独な旅情を感じさせるプロップ。 |
| **#015** | `Material Assign` > `M_Dune_Driftwood` (枯れ木) | 漂流木 | 太陽で白茶けた乾いた木肌。Roughness 0.9。 |
| **#016** | 砂の風下稜線に沿ってシャープなシャドウラインが走るよう調整 | 明暗のメリハリ | 稜線の左が日なた（黄金）、右が日陰（青紫）となる絶景構図。 |
| **#017** | 強烈な太陽光（サンライト: 6000K, 角度 32度） | 砂漠の灼熱太陽光 | 砂丘の稜線のコントラストを極限まで引き出す低角度直射日光。 |
| **#018** | ワールド背景に乾いた砂塵の霞（ヘイズ）カラーを設定 | 大気遠近法 | 遠くの砂丘が砂煙でかすむ臨場感を表現。 |
| **#019** | 全トランスフォーム適用 (`Ctrl + A`) | All Transforms | スケール正規化。 |
| **#020** | Cycles パストレーシングレンダリング | Samples: 32 | 砂粒の微小散乱と砂紋の流麗な陰影を映画クオリティでレンダリング。 |
