# 氷河の氷・氷柱 (Glacial Ice Spikes) 最小単位モデリング手順 ＆ Why深層分析

極寒の洞窟や氷河地帯にそびえる、物理屈折IOR 1.31、内部クラックバンプ、深青の内部散乱光を持つ透明な氷柱・氷塊の全行程レシピ。

---

## 最小単位全手番レシピ (Atomic Steps)

| Step | 操作 (Key / Action) | パラメータ / 設定値 | 手順の目的・理由 (Why) |
| :--- | :--- | :--- | :--- |
| **#001** | `Shift + A` > `Mesh` > `Cylinder` (メイン氷柱 / Central Ice Spike) | Vertices: 6, Radius: 0.22m, Depth: 1.4m, Location: (0, 0, 0.7m) | 六角柱断面から始まるシャープな自然界の氷晶を作成。 |
| **#002** | `Tab` (Edit Mode) > 上端フェースを選択 > `M` > `At Center` (頂点結合) | ピラミッド鋭利先端 | 天に向かって鋭く突き刺さる氷槍（Ice Spear）の切っ先を成形。 |
| **#003** | `Ctrl + R` (Loop Cut) > 柱部に4分割カット > 各頂点をランダムに微小移動 | 自然な氷のねじれ | 人工的な直線を崩し、氷結過程で凍りついた有機的な起伏を表現。 |
| **#004** | `Shift + D` で複製 > `S: 0.65`, `R > Y: 18 deg`, `Location: (0.2m, 0.15m, 0.45m)` | 第2の斜め氷柱 | 親氷柱に寄り添うように斜めに成長したサブスパイアを配置。 |
| **#005** | `Shift + D` で複製 > `S: 0.45`, `R > X: -22 deg`, `Location: (-0.18m, 0.1m, 0.3m)` | 第3の小型氷柱 | 根元に密集する氷の結晶群生（Cluster）を形成。 |
| **#006** | `Shift + A` > `Mesh` > `Cube` (氷河台座 / Glacial Base Slab) | Scale: (1.2m, 1.0m, 0.15m), Location: (0, 0, 0.075m) | 氷柱が生え出す厚い永久凍土・氷床の土台。 |
| **#007** | `Modifier` > `Subdivision Surface` + `Displace` (台座) | Strength: 0.05m, Voronoi | ゴツゴツと割れた流氷のようなリアルなブロック感を作成。 |
| **#008** | 全氷柱と台座を結合 (`Ctrl + J`) | 1つの氷塊アセット化 | 屈折の二重計算エラーを防ぎ、均一な氷の塊としてマテリアルをバインド。 |
| **#009** | `Right Click` > `Shade Smooth` | スムースシェード | ガラス以上のクリアな鏡面反射を演出。 |
| **#010** | シェーダーエディタで新規マテリアル `M_Glacial_Ice` を作成 | 氷シェーダー構築 | 実測氷物理特性の入力。 |
| **#011** | Transmission: `0.95`, Roughness: `0.06`, IOR: `1.309` (氷の物理屈折率) | 氷の真の屈折率 | 水 (1.333) よりわずかに低い氷特有の軽やかでクリアな屈折光。 |
| **#012** | Base Color: 淡いシアンアクアブルー (0.82, 0.94, 1.0, 1.0) | 氷河特有の青み | 長年圧縮された純度の高い氷が放つ神秘的なグレイシャーブルー。 |
| **#013** | 法線に `Bump` (Voronoi + Noise, Scale: 30, Strength: 0.18) を接続 | 内部クラック（ひび割れ） | 氷の内部を走る無数のひび割れと気泡の散乱をプロシージャル表現。 |
| **#014** | `Subsurface Scattering` (Radius: 0.08m, Color: コバルトブルー) | 内部散乱光 | 氷柱の奥深くから青く発光しているかのようなリッチなボリューム感。 |
| **#015** | 足元に極小の氷の破片 (`Icosphere`, 6個) を散乱配置 | 砕けた氷片 | 氷柱から剥落したガラスのような破片ディテール。 |
| **#016** | 内部ポイントライト配置 (シアンブルー, Energy: 40W) | 内包ファンタジー発光 | 魔法の氷塊としてゲーム内で美しく自己主張するライティング。 |
| **#017** | スタジオキーライト（鋭い白色光） | エッジハイライト | 氷の鋭利な稜線（ファセット）にキリッとした光の筋を走らせる。 |
| **#018** | ワールド背景を暗めのダークネイビーに設定 | コントラスト強調 | 氷の透明感とブルーの光彩が最大限に映える背景環境。 |
| **#019** | 全トランスフォーム適用 (`Ctrl + A`) | All Transforms | スケール正規化。 |
| **#020** | Cycles レンダリング (デノイズ ON) | Samples: 32 | ガラスとは一味違う「冷たさ」を感じさせる氷河光彩を忠実に描写。 |
