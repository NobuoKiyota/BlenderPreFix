# 静かな水面・湖 (Calm Water Lake) 最小単位モデリング手順 ＆ Why深層分析

澄んだ湖や静穏な水辺の、物理屈折IOR 1.333、プロシージャル波紋、水底コースティクス光、深度透明度減衰を持つ水面シェーダーの全行程レシピ。

---

## 最小単位全手番レシピ (Atomic Steps)

| Step | 操作 (Key / Action) | パラメータ / 設定値 | 手順の目的・理由 (Why) |
| :--- | :--- | :--- | :--- |
| **#001** | `Shift + A` > `Mesh` > `Plane` (水面メッシュ / Water Surface) | Size: 4.0m, Location: (0, 0, 0.25m) | 湖面の水平境界を作成。 |
| **#002** | `Tab` (Edit Mode) > 細分化 (`Subdivide: 32`) | 1024フェース | 微細な物理波紋の頂点ディスプレイスメントを可能にするトポロジー。 |
| **#003** | `Shift + A` > `Mesh` > `Cube` (湖底・岸辺 / Lake Bed) | Scale: (4.2m, 4.2m, 0.6m), Location: (0, 0, -0.1m) | 水面を通して透けて見える砂利・岩・水底の土台。 |
| **#004** | `Tab` (Edit Mode) > 湖底の中央をなだらかに沈める | 深度勾配 | 浅瀬から水深のある深部へ向かう美しいグラデーションを作る。 |
| **#005** | 水底にランダムな石ころ群 (`Icosphere`, 6個) を配置 | 水底のディテール | 水の透明度と物理屈折の説得力を高めるプロップ。 |
| **#006** | 水面メッシュに `Modifier` > `Displace` | Strength: 0.015m | 風によって生じる穏やかな水面のさざ波をジオメトリ化。 |
| **#007** | ディスプレイス用テクスチャ作成 > Type: `Voronoi` + `Musgrave` | Size: 0.35m | 自然界の波紋特有の、緩やかで有機的な波頭パターンを生成。 |
| **#008** | `Right Click` > `Shade Smooth` (水面) | スムースシェード | 空や環境光を鏡のように歪みなく反射・屈折させる。 |
| **#009** | シェーダーエディタを開く > 新規マテリアル `M_Water_Calm` | Principled BSDF | 物理ベース水シェーダーの構築。 |
| **#010** | Transmission: `1.0`, Roughness: `0.02`, IOR: `1.333` | 水の物理屈折率 | 実測値 1.333 による、水底の物体が浮き上がって見える本物の屈折。 |
| **#011** | Base Color: 薄いエメラルドシアン (0.85, 0.96, 0.98, 1.0) | 清らかな水色 | 不純物のない澄んだ高山湖の水色を定義。 |
| **#012** | `Ray Length` ノードで深さに応じた吸収（Absorption）設定 | 深部ほど濃い青緑 | 浅瀬は透明、深場はコバルトブルーに沈み込む深度フォグ。 |
| **#013** | 法線に `Bump` (Noise Texture, Scale: 60, Strength: 0.08) をブレンド | 微小さざ波ハイライト | 遠景の太陽光を受けてキラキラと輝くスペキュラ反射を生成。 |
| **#014** | `Material Assign` > `M_Lake_Bed_Pebbles` (湖底) | 砂利マテリアル | 濡れた砂利石。Roughness 0.35、BaseColor 灰褐色。 |
| **#015** | 岸辺に水草の束 (`Cylinder`, 細長い葉) を数本配置 | 水生植物アクセント | 水面と陸地の境界を自然に馴染ませる。 |
| **#016** | コースティクス擬似ライト (スポットライト下向き) | Voronoiノード付き | 水の揺らめきが水底に落とす集光模様（Caustics Web）を投影。 |
| **#017** | ワールド環境に空のHDRIまたはスカイテクスチャ設定 | 青空と雲の反射 | 水面に鏡のように映り込む美しい空のスカイラインを担保。 |
| **#018** | Cycles レンダリング設定 (透明バウンス数: 16) | 透明度の多層計算 | 水面を透過して水底の石や砂がクリアに届くよう制限を拡張。 |
| **#019** | 全トランスフォーム適用 (`Ctrl + A`) | All Transforms | スケール正規化。 |
| **#020** | Cycles パストレーシングレンダリング | Samples: 32, Denoise: ON | ガラスとは異なる「水」特有の柔らかな反射と透明度を忠実に描写。 |
