# 苔むした巨岩 (Mossy Cliff Rock) 最小単位モデリング手順 ＆ Why深層分析

深い森や渓流に佇む、多重フラクタル変形のシャープな岩肌スプリットと、上面に生い茂るベルベット調の青苔を持つ巨石の全行程レシピ。

---

## 最小単位全手番レシピ (Atomic Steps)

| Step | 操作 (Key / Action) | パラメータ / 設定値 | 手順の目的・理由 (Why) |
| :--- | :--- | :--- | :--- |
| **#001** | `Shift + A` > `Mesh` > `Cube` (岩ベース / Rock Base) | Size: 1.0m, Location: (0, 0, 0.5m) | 巨岩の原点バウンディングブロックを作成。 |
| **#002** | `Ctrl + 3` (Subdivision Surface: Level 3) | 球体化 | 多方向への変形に耐える均等なポリゴンメッシュを生成。 |
| **#003** | `Modifier` > `Displace` (大スケール岩割れ) > Voronoi Texture | Scale: 1.2, Strength: 0.28m | 自然界の断層・割れ目（Fracture）を模した大きなファセットを形成。 |
| **#004** | `Modifier` > `Displace` (中スケール凹凸) > Musgrave/Noise Texture | Scale: 4.5, Strength: 0.08m | 削られた風化岩のゴツゴツとした中規模のテクスチャを合成。 |
| **#005** | `Tab` (Edit Mode) > `S` > `X: 1.3, Y: 0.9, Z: 0.8` | 扁平な巨石プロポーション | どっしりと地面に腰を下ろした自然な巨岩のシルエット。 |
| **#006** | 底面フェースを選択して `S > Z: 0` でフラット化 | 接地底面の安定 | 地面に安定して埋まり込む底面を作成。 |
| **#007** | ナイフツール (`K`) または `Bisect` で岩の片側を斜めにスパッとカット | 節理（Chiseled Facet） | 氷結や落石でパッカーンと割れた鋭利な平坦面（Cliff Face）を再現。 |
| **#008** | `Right Click` > `Shade Auto Smooth` (Angle: 40°) | 面と曲面の融合 | 丸まった風化面とシャープな割れ目のメリハリを強調。 |
| **#009** | シェーダーエディタで法線Zマスクノードを構築 | `Separate XYZ` > Normal Z | 上を向いている面（Normal Z > 0.4）だけに苔を生やすプロシージャルロジック。 |
| **#010** | ノイズテクスチャで苔の境界を不規則に浸食（Erosion） | 有機的な苔の輪郭 | 直線的なグラデーションではなく、斑点状に広がるリアルな苔の生え際を生成。 |
| **#011** | 苔シェーダー（Principled BSDF）の構築 | 深緑〜黄緑、Sheen: 0.8 | 光を受けたときにベルベットのように白っぽく起毛光沢を放つシェーン効果。 |
| **#012** | 岩肌シェーダー（Principled BSDF）の構築 | 暗灰色花崗岩、Roughness: 0.92 | 水分を含んだリアルな天然石の粗さ。 |
| **#013** | `Mix Shader` で法線Zマスクとノイズを使って苔と岩を完全ブレンド | シームレスマテリアル | 1つのメッシュ上に上面の苔と側面の岩肌が自動マッピングされる。 |
| **#014** | 微小な飛び石 (`Icosphere`, 3個) を巨岩の脇に配置 | こぼれ石ディテール | 親岩から割れて落ちた破片（Talus Scree）を表現。 |
| **#015** | 岩の窪みに小さなキノコ（1本）を配置 | 森の生態系アクセント | 湿度の高い神秘的な太古の森の情景を演出。 |
| **#016** | 苔部分に微小なバンプ（Voronoi: Scale 120, Strength 0.15）を付与 | ふわふわしたコケの毛足 | 拡大レンダリングに耐える超高精細なマテリアル解像度。 |
| **#017** | スタジオキーライト（斜め横からの低角度光） | 陰影の強調 | 岩の割れ目の深さと苔の起毛ハイライトをドラマチックに照射。 |
| **#018** | アンビエントオクルージョン（AO）を強めに設定 | 割れ目の深い影 | 岩の隙間に溜まる暗がりをリアルに計算。 |
| **#019** | 全トランスフォーム適用 (`Ctrl + A`) | All Transforms | スケール正規化。 |
| **#020** | Cycles パストレーシングレンダリング | Samples: 32 | 鉱物のザラつきと植物の柔らかな質感のコントラストを描写。 |
